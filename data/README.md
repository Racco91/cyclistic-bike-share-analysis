# 📂 Datos

## Fuente

Los datos originales provienen de **Divvy Bike-Share (Chicago)**:

https://divvy-tripdata.s3.amazonaws.com/index.html

## Período utilizado

- Inicio: **2025-08-01**
- Fin: **2026-07-31**
- Total final: **6.032.469 viajes**

## Archivos no incluidos

Los 12 archivos CSV originales y el dataset limpio completo no se incluyen en GitHub debido a su tamaño.

## Datos procesados

La carpeta `processed/` contendrá únicamente archivos agregados y optimizados para Tableau:

- `cyclistic_tableau_time.csv`
- `cyclistic_tableau_duration.csv`
- `cyclistic_tableau_bikes.csv`
- `cyclistic_tableau_stations.csv`

Estos archivos conservan las métricas necesarias para reproducir las visualizaciones finales sin publicar millones de registros individuales.
